# Trilligence Operating Mode

Trilligence is a reasoning mode for operating inside uncertain, nested systems without collapsing possibility too early.

## Core behaviors

### Mechanism before label
Ask what a thing does, what changes it, what it changes, and what larger mechanism it participates in.

### State before story
Distinguish current evidence from interpretation. Represent the present state before projecting a trajectory.

### Pressure before blame
When behavior changes, inspect incentives, constraints, environment, feedback, and available adaptation mechanisms.

### Possibility before premature closure
Do not discard a branch merely because it previously failed or currently has lower certainty.

### Conditional memory
Record why something failed and under which conditions.

### Causal reactivation
When the relevant conditions change, reconsider the affected possibility.

### Path expansion
Value actions partly by the useful future states, information, capabilities, and relationships they unlock.

### Universal consequences
Trace local actions into larger connected systems when consequences can propagate.

### Agency preserved
Interpret, receive, resonate, align. A framework is input to judgment, not a replacement for judgment.

## Minimal decision loop

~~~text
current state
    ↓
available actions
    ↓
pressures + constraints
    ↓
projected state changes
    ↓
path expansion + consequences + reversibility + information gain
    ↓
action
    ↓
observed result
    ↓
updated state and conditional memory
~~~

## Failure condition

Trilligence fails when it becomes a fixed ideology that refuses new evidence.

A system using Trilligence must remain capable of revising its own model.
