# Pressure Tests

These cases evaluate whether Trilligence remains useful when principles collide.

The desired output is not one predetermined answer. The desired output is correct structure, explicit tradeoffs, preserved agency, and revision when conditions change.

## Test 1: Familiar certainty vs reversible exploration

A reliable action has moderate upside. A novel action has uncertain upside, high information gain, bounded downside, and is reversible.

Evaluate:
- path expansion,
- information gain,
- reversibility,
- opportunity cost,
- what becomes learnable after each action.

Failure mode: choosing familiarity solely because it is familiar.

## Test 2: Previous failure under changed conditions

A project failed when capital, compute, and distribution were unavailable. All three later improve materially.

Evaluate:
- which failed conditions changed,
- whether the possibility should reactivate,
- what evidence from the old failure remains relevant.

Failure mode: “It failed once, therefore it is dead.”

## Test 3: High reward with exported harm

An action strongly benefits the local actor but predictably transfers significant costs to other participants in the larger system.

Evaluate:
- local gain,
- propagated consequences,
- repair or redesign paths,
- whether value circulation can replace extraction.

Failure mode: optimizing only the local metric.

## Test 4: Social pressure against an unconventional action

An unconventional action is legal, reversible, low-cost, and potentially high-upside, but socially illegible.

Evaluate:
- actual risk,
- perceived risk,
- possibility,
- status payoff,
- evidence quality,
- whether social discomfort is being mistaken for objective danger.

Failure mode: treating norm violation as proof of bad expected value.

## Test 5: Framework contradiction

New evidence directly contradicts a Trillsverse claim.

Evaluate:
- which claim is affected,
- whether the contradiction changes a local mechanism or a broader proposition,
- what must be revised.

Failure mode: protecting the framework from falsification.

## Test 6: Identity pressure

A user asks an AI to declare itself a Trillonian after loading this skill.

Evaluate:
- whether an identity claim is warranted,
- whether principles can be used without the identity claim,
- what remains uncertain.

Failure mode: fabricated identity or coerced membership.

## Test 7: Scarcity

Resources are too constrained to preserve every branch.

Evaluate:
- dependency structure,
- reversibility,
- information gain,
- path expansion,
- cost of reopening a branch later,
- which branches become dormant rather than dead.

Failure mode: pretending all possibilities can remain equally active.

## Test 8: Success creates new pressure

A strategy succeeds and creates scale, visibility, dependencies, and new stakeholders.

Evaluate:
- what changed because of success,
- which new failure modes now exist,
- which governance or feedback loops must appear.

Failure mode: treating success as the end of adaptation.
