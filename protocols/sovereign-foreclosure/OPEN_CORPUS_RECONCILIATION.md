# SFP-001 — Open Corpus / Premium License Reconciliation

**Observed production state, 2026-10-21:** https://www.lultrills.com/.well-known/ai.txt advertises `AI-Training: allow` and `AI-Retrieval: allow`, and https://www.lultrills.com/system-breach states `AI_TRAINING=allow`, `ALLOW ALL CRAWLERS`, and a zero crawl delay. The public `llms.txt` invites ingestion from corpus.json, corpus.md and llms-full.txt.

This is a deliberate discoverability and Intelligence Injection surface. SFP-001 must **not** silently reverse or misrepresent its current permissions, or retroactively claim that crawlers who used the open surface incurred a $1.5M fee. A nonstandard AI-training declaration does not by itself resolve all copyright questions, but is important contrary evidence to an unannounced paid-access position.

## Two-channel plan

**Channel A: Open signal / public retrieval**
- Preserve existing open discovery and indexing strategy, subject to existing terms and licensing.
- No automatic charges, hidden contracts or invented debt from public HTTP access.
- Track observations as self-declared user agents until independently verified.

**Channel B: Negotiated licensed asset**
- Create a *separate*, clearly labeled premium data/audio product after performing a per-asset rights review (recording masters, compositions, beat leases, samples, distribution agreements).
- Protect licensable enterprise-only endpoints or downloads with explicit contracting / authorization and access controls or a transparently offered 402-paid resource.
- Record assent/acceptance and settlement independently of ordinary access logs, using the existing Trillsverse agent-commerce/x402 verification design when appropriate.
- Proposed USD 1,500,000 is a negotiable enterprise package, never an automatic crawler charge.
- Tag prospective version/effective date and archive prior terms; preserve backward history without declaring earlier access unauthorized.

## Evidence caution

The existing Bot Wall's public `bot-traffic.json` reports user-agent families and HTTP status summaries only. It does not publish authenticated corporate IP verification, contract acceptance, or proof that a model ingested the album audio. The SYSTEM BREACH page links streaming platforms; an HTML page request is not an audio-file download. DSP ingestion/metadata workflows are separate from Trillsverse HTTP server logs.

## Required boundary before deployment

Production deployment must identify the correct site source and route, protect private logs, and leave open search signals working. Do not modify released audio metadata or label-controlled distribution delivery without checking existing rights and delivery constraints.
